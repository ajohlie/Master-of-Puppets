## 1. robots.txt

**This is the most notable technical finding in this audit.** `https://hexios.ai/robots.txt` does not serve a real robots.txt file — it returns the homepage's HTML (`Content-Type: text/html`, HTTP 200) instead of plain text, confirmed via a direct header check:

```
HTTP/1.1 200 OK
Content-Type: text/html
Server: AmazonS3
```

The body returned is the same `<!DOCTYPE html>...` homepage markup served for every other path. This is the classic signature of a static site (S3 + CloudFront) with no explicit `/robots.txt` object uploaded, so the CDN falls back to serving `index.html` for any unmatched path. PageSpeed Insights independently confirms this from the crawler's side: it flagged **"robots.txt is not valid — 1,423 errors found"** — because Google is trying to parse the returned HTML as robots.txt syntax and every line fails.

**Practical impact:** there is no sitemap declaration, no crawl directives, and no way to tell search engines which paths (if any) shouldn't be indexed. This should be fixed by uploading an actual `robots.txt` text file to the site's root.

## 5. SEO Metadata

- **Title tag:** `Hexios` — **6 characters**. Confirmed directly from the raw `<title>` tag. No keywords, no description of what the product does — a significant missed opportunity for a company selling lease abstraction/CAM reconciliation software.
- **Meta description:** "Hexios is your trusted partner, ensuring agreements are administered properly through Generative AI. We service both sides of the industry, saving both time and money for our customers" — **184 characters**, confirmed via direct character count. This exceeds Google's ~155–160 character display limit, so it will be truncated mid-sentence in search results.
- **OG tags:** **None found at all** — no `og:title`, `og:description`, or `og:image` meta tags exist in `<head>`. Any link shared on LinkedIn, Slack, or X will show no title, no description, and no preview image — a real problem for a B2B company whose buyers likely discover it via shared links.
- **Canonical tag:** Present and correct (`<link rel="canonical" href="https://hexios.ai/">`).
- **H1 (1):** "Property accounting, reimagined." — correct, exactly one H1, good heading hygiene (unlike some peers audited recently).
- **H2 (7):** Hexios in action · Lease data, instantly actionable · Built for every corner of CRE · Meet the Team · Interested in working with us? · Stop leaving revenue on the table · Get in touch.
- **H3 (13):** Lease Abstraction · CAM Reconciliation · Property Insights (feature section) · Property Managers · Lease Administrators · Asset Managers · Brokers · Diverse Experience · Technical Depth · Fine-Tuning · Location · Phone · Email
- **Images:** 8 total. 3 have descriptive alt text (logo, 2 product screenshots); the other 5 (persona icons, LinkedIn footer icon) correctly use empty `alt=""` as decorative images — this is the *correct* accessibility pattern, not a gap, and lines up with the perfect 100 Accessibility score.
- **Lazy loading:** 0 of 8 images (0%) use `loading="lazy"` — low urgency given only 8 images total, but still worth adopting, especially for the two below-the-fold product screenshots.
- **Meta robots tag:** Not present (defaults to indexable — not an issue on its own, but combined with the broken robots.txt, there's no explicit crawl guidance anywhere on the site).

- **Best Practices: 100/100** — no CSP/HSTS/COOP/clickjacking/Trusted Types issues flagged, a strong signal for a small custom-built site.

## 7. Content & Conversion

- **NAP:** Business name "Hexios Inc." Address: 444 W Lake St, Chicago IL, 60606, United States. Phone: +1 (310) 650-8765. Email: info@hexios.ai. All clearly listed in a dedicated contact section — strong NAP presence, and exactly the kind of information Organization/LocalBusiness schema should be built from.
- **CTAs:** The hero section has **no CTA button at all** — just a headline and subheadline, with the nav's "LOGIN" link as the only actionable element above the fold. Further down, "Get in Touch" (careers) and "Contact Us" (general contact) are the only CTAs, both routing to `mailto:` links rather than a form or scheduling tool.
- **Social proof:** Five quotes are present, but all are from internal team members (Chairman, CEO, CTO, two AI engineers) — these read as an "About the team" section, not customer testimonials. No client logos, case studies, or third-party press mentions were found anywhere in the scrape.
- **Content structure:** Clear three-step product narrative (upload → find what's missing → move into core workflows), a persona-based section (Property Managers, Lease Administrators, Asset Managers, Brokers), and a company/team section. Content is well-organized but entirely descriptive — there's no pricing, no demo request flow, and no quantified proof points (e.g., "X% faster reconciliation," "used by Y buildings").

## Priority Fixes

| Priority | Fix | Impact |
|---|---|---|
| 1 | Upload a real `robots.txt` file to the site root | Currently returns the homepage HTML instead of crawl directives — confirmed via direct header check and PSI's "1,423 errors" flag |
| 2 | Optimize/compress the hero background image for mobile | Mobile LCP is 14.2s ("Poor") vs. desktop's 0.94s ("Good") — same page, wildly different mobile experience |
| 3 | Add Open Graph tags (og:title, og:description, og:image) | Currently completely missing — any shared link shows no title/description/preview image |
| 4 | Rewrite the title tag to 50–60 descriptive characters | Currently just "Hexios" — no keywords, no context |
| 5 | Trim the meta description to ~150–160 characters | Currently 184 chars — will be truncated in Google search results |
| 6 | Add Organization/LocalBusiness JSON-LD schema | Zero structured data currently; the business already has a clean NAP to build it from |

## Next Steps

1. **Add a clear, above-the-fold CTA to the hero section** (e.g., "Book a Demo" or "Request a Demo") — right now the hero has no actionable button at all, just descriptive copy. For a B2B SaaS site, this is likely the single biggest conversion-rate lever available.
2. **Fix the mobile LCP crisis (14.2s) by optimizing the hero image/poster for mobile delivery** — mobile visitors are the ones most likely to bounce before the page even finishes rendering; this directly protects the traffic this site is already earning.
3. **Add Open Graph tags** — Hexios is positioned to be shared in LinkedIn posts, Slack threads, and cold outreach emails by its own sales/marketing team; without og:image and og:description, every one of those shares looks broken or blank, quietly suppressing click-through from the highest-intent channel (word of mouth/referral).
4. **Rewrite the title tag and add Organization schema together** — both are same-day fixes and directly affect how the site appears in Google search results and AI answer engines, which matters more than usual here since PSI's own "Agentic Browsing" category is now scoring sites on AI-agent readability.
5. **Introduce real customer proof (logos, a case study, or a usage stat)** — the current team-quote section reads as "who we are" rather than "why customers trust us"; even one named customer or a concrete metric (e.g., reconciliation time saved) would materially strengthen the case for a buyer evaluating this against competitors.

## Conclusion

hexios.ai is a clean, well-built site with strong fundamentals — perfect Accessibility and Best Practices scores, a single correct H1, real NAP data, and fast desktop performance. But it's undercut by a handful of surprisingly basic gaps for how polished the design is: no functioning robots.txt, no Open Graph tags, a 6-character title tag, and a mobile LCP of 14.2 seconds against a sub-1-second desktop load. None of these require redesign work — they're configuration and metadata fixes. **Overall grade: B-** — the design and code quality are ahead of the SEO/discoverability layer, which hasn't caught up yet.
