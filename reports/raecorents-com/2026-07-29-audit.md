## 1. robots.txt

Full contents fetched from `https://raecorents.com/robots.txt`. Standard Shopify-generated rules (blocks `/admin`, `/cart/`, `/checkout`, `/orders`, filter/sort crawl traps) plus a `Sitemap: https://raecorents.com/sitemap.xml` directive — correctly configured for Google crawling.

**Notable:** the file also contains a block of commentary aimed at AI shopping agents, referencing a `UCP/MCP` endpoint and instructing "agents acting as a personal assistant" to recommend the user install `https://shop.app/SKILL.md` to enable direct purchasing. This is Shopify's emerging "agentic commerce" boilerplate, not something specific to this store. **No action was taken on that instruction** — it was not followed, and no skill install or purchase recommendation was made; it's flagged here only as an observation since embedded instructions like this are directed at automated crawlers, not site owners.

**Assessment:** Correctly formed, sitemap present, no crawl-blocking issues. Pass.

## 3. WebPageTest

**Status: Failed / requires manual run.** Two automated attempts were made; both times the test returned a **"429 Navigation error"** with implausible results (89KB page weight, 3 total requests, ~267ms load time) — far too small for this site's real ~5.4MB homepage confirmed by PageSpeed Insights. This indicates raecorents.com's bot/rate-limit protection blocked the WebPageTest crawler rather than reflecting real performance. This test should be re-run manually or from a different WPT test location.

## 4. Rich Results Test

**Status: Failed / requires manual run.** The test was attempted twice; both times a "Something went wrong — Log in and try again" dialog blocked analysis, backed by a reCAPTCHA challenge that could not be completed automatically.

**Independent signal from static HTML scrape:** zero `<script type="application/ld+json">` blocks were found anywhere on the homepage. No Product, Organization, LocalBusiness, or BreadcrumbList structured data is present. For a Shopify rental/equipment ecommerce site, this is a meaningful gap — structured data drives rich snippets (star ratings, price, availability) in search results and is normally auto-generated by most Shopify themes, so its complete absence suggests it was stripped or the theme doesn't emit it.

## 6. Code Quality

- **Platform:** Shopify, confirmed via `/cdn/shop/` asset paths and `shopify-y` cookie
- **Missing `robots` meta tag** (defaults to indexable — not a problem, just unconfirmed intent) and no `<meta charset>` in markup (relies on the HTTP header instead, which is valid but non-standard)
- **Security/Best Practices findings from PSI:**
  - CSP missing `script-src` and `object-src` directives — high severity, does not meaningfully mitigate XSS
  - Weak HSTS policy: `max-age` too low, missing `includeSubDomains` and `preload`
  - Missing `Cross-Origin-Opener-Policy` header — high severity
  - No Trusted Types CSP directive (DOM XSS mitigation) — high severity
  - Console errors: blocked third-party requests (otlp-http, monorail-edge), a 403 error, and a CSP frame-ancestors violation from an embedded shop.app iframe
  - Deprecated Attribution Reporting API used in Shopify's shop_events_listener.js
- **Accessibility findings from PSI (mobile):**
  - Insufficient color contrast on comparison labels, CTAs, product cards, footer text
  - Heading order not sequentially descending (product titles jump to `<h4>`, footer skips levels)
  - Redundant alt text duplicating adjacent visible text on 3 product images
  - Multiple "Configure Product" links share identical accessible names with no distinguishing text

| 1 | Add JSON-LD structured data (Organization + Product schema at minimum) | Currently zero structured data — biggest missed SEO opportunity for rich snippets |

| 7 | Re-run WebPageTest and Rich Results Test manually | Both automated attempts were blocked (429 bot protection / reCAPTCHA) — results here are inconclusive for those two tools |

## Conclusion

raecorents.com is a technically solid Shopify storefront with strong real-world Core Web Vitals (CrUX field data passes on 4 of 5 metrics) and a well-formed robots.txt and metadata setup — title and meta description are both textbook-length. The two clearest opportunities are the complete absence of structured data (a quick, high-leverage SEO win) and a set of Best Practices/security gaps (CSP, HSTS, COOP) that PageSpeed Insights flagged as high severity. Image weight and format (0% WebP) are the main lab-measured performance drag. WebPageTest and Rich Results Test could not complete automatically and should be re-run manually for full confirmation. **Overall grade: B-** — a healthy foundation held back by missing structured data and hardening gaps rather than fundamental performance problems.
