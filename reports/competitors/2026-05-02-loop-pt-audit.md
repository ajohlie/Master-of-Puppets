## Indexability Signals

- **No noindex pages found.** All 25 pages carry `robots: index, follow, max-image-preview:large, max-snippet:-1, max-video-preview:-1`.
- **No canonical issues detected** in the crawled data (all `og:url` values match the page URL).
- **Boilerplate title formula overused:** 20 of 25 titles use the pattern `[Keyword] in Chicago, IL and Barrington, IL | Loop Physical Therapy`. This is SEO-functional but creates title truncation across virtually all pages (most land in the 70–84 char range, well above the ~60-char display threshold).
- **Worst offender:** "Recover from Motor Vehicle Accident Injuries in Chicago, IL and Barrington, IL | Loop Physical Therapy" — 101 characters.
- **WordPress/WP Rocket:** Site runs WordPress 6.9.4 with WP Rocket 3.21.1 and WP Schema Pro 2.11.1 (see body class). Schema Pro plugin is present but its JSON-LD output was not captured in the Firecrawl HTML — this may be a rendering issue rather than absent schema; worth verifying with a manual Google Rich Results Test.

### Schema Markup

**No schema markup was detected in any crawled HTML.** 

The body class `wp-schema-pro-2.11.1` confirms the WP Schema Pro plugin is installed and active. However, no `schema.org` references or `@type` JSON-LD blocks appeared in the captured HTML. Possible explanations:
- The plugin outputs schema in a `<script type="application/ld+json">` block that Firecrawl may not have rendered (JavaScript-dependent output).
- Schema may be injected after page load.

**Recommendation:** Verify schema output manually via Google's Rich Results Test at https://search.google.com/test/rich-results for a representative URL. If schema is missing, this is a significant gap given that LocalBusiness/MedicalBusiness + Physician schema is standard for PT clinics.

## Additional SEO Observations

1. **Duplicate content risk from geo-stuffing:** Every condition page repeats the same list of 5 locations (Edgewater, The Chicago Loop, West Loop Chicago, Terrace Clinic, Barrington) multiple times in the body copy — typically 4–6 times per page. This is a legacy local SEO pattern that modern algorithms may treat as keyword stuffing.

2. **WP Rocket caching active:** Most pages carry a `<!-- Debug: cached@ -->` WP Rocket comment, indicating aggressive caching. Page speed should be good.

3. **No "noindex" on internal utility pages:** The Community Partnerships page and Join Our Team page are indexed, low-content pages with minimal SEO value.

4. **Google Tag Manager present** on all pages, suggesting conversion tracking is in place.

5. **Zocdoc integration:** Booking goes to Zocdoc (`/practice/loop-physical-therapy-centers-45534`), not a native form. This may reduce conversion data ownership and create a dependency on a third-party platform.
